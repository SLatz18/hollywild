# Neighborhood expansion contract

Native device game. Existing campaign and legacy tests preserved. No required story grind or timing claim. Four independent three-mission arcs (12 missions), six one-mission encounters, four one-mission property projects. All can progress independently; main campaign is unaffected. ASCII prose, 18-column wrapping through wrapCampaignPages. No timers.

## Authored schema: content/side-stories.json
Object {title, tracks}. Each track: {id, kind, label, title, home, intro, missions, complete, perk?, requires?}.
- id lower snake case, unique. kind arc / encounter / project. label ASCII <=7 chars for menus. title readable. home scene ID below. intro, complete arrays of prose pages.
- missions array: arc exactly 3, others exactly 1. Each {title, intro, steps, outro, reward:{coins,salvage}}. Arcs 5..7 meaningful steps per mission; encounter 3..4; project 4..5. Rewards conservative, total side scrap <=35 to avoid gratuitous storage pressure. Coins 25..60 per mission. Project may reward zero Coins; no mandatory resource spend beyond property purchase.
- Each step {node, type, hint, pages}; node is scene ID, handled by separate side_<scene> actor. type talk/collect/puzzle/choice. puzzle has options (2..4 ASCII <=7 chars), answer (1-based), wrong pages. choice has options, outcomes page arrays; stores side_<trackid>_choice. At most ONE choice per track, with later reactions [{value,pages}] on later steps, or completion pages through an optional completionReactions array on track. Every choice option must have a meaningful later reaction. Side choices cannot affect main-story state.
- requires optional existing ownership variable cocoa/parcel/toolworks/flats, projects only. Starting a project requires ownership; all public geography remains open.
- perk optional one of perk_courier,perk_listing,perk_neighbors,perk_rivals,perk_cocoa,perk_parcel,perk_toolworks,perk_flats. Fixed each track completion sets its perk=1. Arcs courier/listing/neighbors/rivals respectively. Projects corresponding property.
- Benefits supplied in root integration: courier +5 Coins/delivery; listing 20-Coin discount on property purchases; neighbors +1 extra Cheer per donation up to100; rivals +1 scrap per salvage job. Property improvements cocoa +4 Coins/job, parcel +6 Coins/job, toolworks +1 scrap/job, flats +3 Coins/job. Ordinary successful jobs only, no passive clock ticks. Own before project, no new charge to finish. Describe benefits accurately in prose.

## Native state and routing
Append after existing 90 globals, preserving IDs. Per track side_<id>_mission (0 unstarted, 1..N active, N+1 complete), side_<id>_step (0-based), side_<id>_choice. Perk flags appended. No separate completed count needed: mission state guards rewards. Completion only when step==length, no active ordinary job, enough wallet/storage. If blocked preserve pending step, retry via its final node or Side journal. Never multiple step advances per interaction. Never automatic production ticks.

Engine exports loadSideStories(root), sideVariableNames(data), createSideEngine(data, {ev,iff,set,add,text,menu,share}) returning node(scene), journal(). Node and journal use category menu Stories/Moments/Build/Back; then track menu ordered by data filtered kind. Node filters tracks that have home==scene or any step.node==scene. Select track starts via Begin/Back at home, performs ONE active step if at proper node, otherwise shows exact next hint or completion. Journal never starts or advances a step; it may claim pending rewards. Category menu indexes 1 arc,2 encounter,3 project. Track menus may have up to6 tracks, Back last, cancelOnB true. Always nested menu dispatch, because menu overwrites shared choice.

Root owns create-game.mjs integration, world-layout.json, generated resources, production benefits/build/release/docs. Engine worker owns scripts/side-events.mjs and source interpreter tests scripts/check-side.mjs. Content worker owns content/side-stories.json, docs/SIDE_STORIES.md. QA worker owns scripts/create-side-tests.py, tests/side-*.jsonl, scripts/test-game.py, scripts/emulator-qa.py if needed for timing only.
